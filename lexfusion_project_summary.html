📌 Executive Summary

LexFusion transforms traditional legal research into an autonomous, multi-agent courtroom simulation. By orchestrating three specialized AI agents (Prosecution, Defence, and Judge) within a LangGraph StateGraph, LexFusion cross-examines legal documents, exposes argument weaknesses, eliminates single-shot AI bias, and produces grounded legal rulings complete with confidence scoring.

🏛️ System Architecture & Agent Workflow

Unlike traditional Q&A systems that output single-shot answers, LexFusion executes a structured multi-turn legal debate over retrieved vector context:

[ User Query + Uploaded Legal PDFs ] │ ▼ [ Vector Store RAG Retrieval ] ──► (ChromaDB + SentenceTransformers all-MiniLM-L6-v2) │ ▼ [ LangGraph State Machine Execution ] ├── 🔴 Advocate A (Prosecution Node) ──► Constructs Plaintiff argument using IRAC method ├── 🔵 Advocate B (Defence Node) ──► Direct rebuttal + Defence counter-argument └── 🔄 Round Check Edge (1 to 3 Rounds) ──► Rebuttal Loop until MAX_ROUNDS reached │ ▼ ⚖️ Synthesis Judge Node ─────────────► Neutral evaluation & confidence score calculation │ ▼ [ Streamlit UI Render + Interactive Analytics + PDF Brief Export ]

⚖️ Multi-Agent Deep Dive

Agent 1 Advocate A (Prosecution)

Represents the affirmative / plaintiff position. Builds formal legal claims structured around the IRAC (Issue, Rule, Application, Conclusion) framework strictly grounded in retrieved evidence. Pre-empts counterarguments.

Agent 2 Advocate B (Defence)

Represents the respondent / defence position. Performs point-by-point rebuttals of Advocate A's submissions, identifies evidentiary or procedural gaps, and constructs an independent defence case.

Agent 3 Presiding Judge (Synthesis)

Acts as a neutral, impartial judicial arbiter. Synthesizes arguments from both sides, evaluates evidence quality, parses a quantitative Confidence Score (0-100%), highlights strengths/weaknesses, and issues a final binding legal opinion.

🌟 Winning Unique Features

  • Dual-Mode Execution Architecture: Automatic fallback to in-process local agents when FastAPI server is offline, enabling zero-downtime Streamlit Cloud deployments.
  • Adversarial Legal Stress-Testing: Exposes blind spots and weak contract clauses by forcing opposing AI perspectives.
  • Visual Legal Analytics: Interactive Plotly Multi-Axis Legal Strength Radar Chart & Confidence Radial Meter.
  • Grounded Verification Engine: Direct source attribution (`[██████████░] 94% match`) ensures zero hallucination.
  • Global Multilingual Support: All 3 agents seamlessly debate in any of 50 selected global languages.
